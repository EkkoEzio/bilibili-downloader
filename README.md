# bilibili download

本地网页应用,下载 B 站视频。支持大会员高画质(1080P+/4K)。

## 快速开始

1. **双击 `启动.command`**(首次会自动创建虚拟环境并装依赖,稍等片刻)
2. 浏览器自动打开 `http://localhost:5050`(若没自动打开,手动访问)
3. 选择登录方式 → 粘贴视频地址 → 解析 → 选清晰度 → 下载

## 环境要求

- macOS(已在 Apple Silicon 测试)
- 已安装 ffmpeg(下载引擎依赖):`brew install ffmpeg`
- Python 3.10+(首次启动会建 `.venv` 并装 yt-dlp / flask / qrcode / pillow)

## 三种登录方式

应用右上角显示当前登录状态。登录区有三个标签页:

### 1. 扫码登录(推荐)
- 点「显示二维码」
- 用**手机 B 站 App 扫码**确认(和平时登录一样)
- 一次登录长期有效;失效后重新扫一次即可
- ✅ 最安全,密码不经过本软件

### 2. 使用 Edge
- 前提:你已在 Edge 浏览器登录过 bilibili.com
- 点「使用 Edge 登录态」,软件直接读取 Edge 中已有的登录态
- ✅ 最省事,如果平时用 Edge 登 B 站,推荐这个

### 3. cookies.txt(兜底)
- 浏览器装扩展 **"Get cookies.txt"**(或类似)
- 在 bilibili.com 页面用扩展导出 cookies.txt
- 把内容粘贴到文本框,点「导入 cookies.txt」

## 功能一览

### 「我的B站」5 个内容浏览 tab
- **观看历史** — 自动加载,含观看进度百分比
- **关注更新** — 关注 UP 主最新投稿,合并按时间倒序
- **UP 清单** — 自定义 UP 清单 + 一键刷新看新增(增量检测)
- **收藏夹** — 我的所有收藏夹列表 + 逐个看内容
- **稍后再看** — 待看清单

### 下载
- **单视频解析**:粘贴链接 → 选清晰度 → 下载(8K/4K/1080P/720P/480P/360P 都有)
- **分集(多P)视频**:自动识别分集 → 选单集或一键多选
- **批量下载**:多链接一次粘贴 / 收藏夹 / 合集 / UP 清单批量
- **DASH 高画质**:自动合并音视频(ffmpeg),输出单个 mp4

### 下载管理
- 实时进度条 + 速度 + 剩余时间
- 失败自动重试(最多 3 次,带退避)
- 下载中可取消
- 完成后「在 Finder 中显示」一键定位文件
- 队列区支持多选删除(可选删文件或仅删记录) + 清除所有记录

### 搜索过滤
- 列表顶部搜索框,按标题/UP 主实时筛选
- 切换 tab 自动清空搜索

### 设置
- ⚙ 设置区(折叠):下载目录、同时下载数(1-4)、单任务限速、主题
- 所有设置持久化到 `data/config.json`,重启仍在
- 主题:浅色 / 深色 / 跟随系统(切换按钮在 header)

### 视图
- 列表 / 网格切换(网格像 B 站卡片)
- 深色模式(CSS 变量 + body.dark)
- 顶部统计条:📦总下载数 / 💾总大小 / 📅本月 / 📆今日

## 常见问题

**Q: 下载时提示"该清晰度需大会员"或只给低画质?**
A: 没带登录态或没大会员。扫码登录或切换 Edge 模式,确认账号是大会员。

**Q: 登录突然失效?**
A: B 站 cookie 会过期。重新扫一次码,或重新点「使用 Edge 登录态」刷新。

**Q: 扫码一直"等待扫码"?**
A: 二维码有效期约 3 分钟,过期后重新点「显示二维码」生成新的。

**Q: 端口 5050 被占用?**
A: 改 `config.py` 里的 `PORT`(默认避开 macOS ControlCenter 的 5000)。

**Q: 关注更新/UP 清单只返回少量项?**
A: B 站对 arc/search 接口有限流,密集调用会触发;等几分钟再刷新即可。

**Q: 想换下载目录?**
A: ⚙ 设置 → 改下载目录 → 保存。后续所有下载保存到新目录。

**Q: 想暂停后台下载,不想占浏览器?**
A: 当前需要保持浏览器 tab 开着。不打包成桌面应用(见 `docs/BACKLOG.md` 中 B6 说明)。

## 项目结构

```
├── app.py              # Flask 路由层
├── bilibili_auth.py    # 扫码/Edge/cookie 登录 + 内容 API
├── downloader.py       # yt-dlp 封装(解析/下载/重试/进度/取消)
├── quality.py          # 清晰度标注与 format 归一化
├── config.py           # 运行时配置(目录/并发/限速/主题)
├── up_list.py          # A3 自定义 UP 清单数据层
├── templates/index.html# 单页前端
├── tests/              # 单元测试(16 个)
├── docs/               # BACKLOG 与设计文档
├── data/               # 运行时数据(tasks/config/up_list/cookies/...)
├── 启动.command         # Mac 双击启动
└── requirements.txt
```

## 数据隐私

所有数据(登录态、任务历史、UP 清单、设置) 全部存在本地 `data/` 目录,**不上传任何服务器**。扫码二维码走的是 B 站官方接口;Edge 模式只读本机浏览器 cookie。
