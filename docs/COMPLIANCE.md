# 合规与法律风险边界

> 本文件回答两个问题：①「B 站视频下载」这类工具是否合法；②怎样使用/发布才尽量合法。
> 评估基于 2026-08 公开检索(用户协议、判例、著作权法、反不正当竞争法、GitHub DMCA 记录)，
> **非法律意见**。重大决策请咨询执业律师。

## 结论速览

| 使用形态 | 风险 | 说明 |
|---|---|---|
| 个人自用、不开源 | 低 | 自存不传播不触发信息网络传播权；无追责先例。主要风险是**违反 B 站用户协议 → 限流/封号** |
| 个人自用 + MIT 开源免费 | 中 | 无针对下载工具的 DMCA 先例，但存在"帮助侵权/不正当竞争"理论风险 |
| 盈利 / 向公众提供服务 | 高 | 直接落入反不正当竞争法互联网条款 + 著作权侵权，参照判例赔偿数十万至 490 万 |

## 关键定性：违约 ≠ 违法

两条边界非常清晰：

1. **不规避技术措施 + 不对外传播 = 基本不违法，但违反 B 站用户协议**。
   违反协议是**合同违约**，后果是 B 站限流、封禁账号；不是刑事/民事违法。
2. **规避 DRM/付费墙，或把下载内容再传播 = 违法**。
   前者触碰《著作权法》第 49/53 条技术保护条款乃至《刑法》第 217 条；
   后者侵犯信息网络传播权。

本项目功能全部落在**第 1 条**的安全区：只用自己账号登录、只下载账号有权观看的
免费内容、不破解付费/大会员内容、下载物仅本地存档。

## 各功能风险分级(本项目实际功能)

| 功能 | 等级 | 依据 |
|---|---|---|
| 登录自己账号浏览历史/收藏/关注 | 低 | 官方 API + 自有数据；仅协议层违约风险(封号) |
| 下载有权观看的免费视频自存 | 中低 | 无 DRM 不涉技术措施；自存不传播不触发信网权 |
| 仅提取音频 | 中低 | 定性同上；但音频再分发即侵权 |
| 保存弹幕/字幕/封面 | 低-中 | 自存低风险；封面/字幕属他人作品，**分发即侵权** |
| 低频自动下载(UP 清单) | 中 | 触碰协议"自动程序"条款；已用保守限频缓解(见下) |
| (未做)绕过付费/大会员 | 高 | **本项目明确不做** |

## 自动下载的特别处理

自动下载是本工具风险最高的一块：它属于 B 站用户协议中“以任何自动程序获取平台内容”
的场景，且无对应判例。为降低风险，实现上刻意保守：

- UP 之间请求间隔 **≥ 5 秒**（`auto_refresh.UP_INTERVAL`），串行执行；
- 轮询间隔下限 **10 分钟**（`config.AUTO_REFRESH_MIN`，UI 不可调破）；
- 同一时刻只跑一轮：进行中再次触发直接跳过、不排队、不发请求；
- 只处理用户自己主动加入清单的 UP，加入时以当前最新投稿为基线，不批量补历史；
- 每个 UP 单轮最多 3 页只是请求预算；没越过旧游标时持久化续扫点，不把未扫描内容
  标记为已见；游标保存同秒 BVID 集合，避免同秒投稿遗漏；
- 自动任务失败或重启中断后从本地任务史指数退避重试（10 分钟起步，24 小时封顶），
  不通过密集重扫 UP 接口恢复任务。

> 5 秒 UP 间隔与 10 分钟轮询下限由 `tests/test_auto_refresh.py` 和本文档绑定，
> 改代码不改文档（或反之）会直接跑挂测试。

## 统一请求治理（v2.2）

自动追更以外的登录、内容浏览、弹幕和媒体解析链路也共享同一账号级治理器：

- 单进程最多 **2 个 B 站上游请求同时在途**；
- `sensitive` 至少 1.5 秒并附加 0–0.35 秒抖动，`bulk` 为 0.25 秒 +
  0–0.08 秒，`media` 为 0.5 秒 + 0–0.15 秒；
- HTTP/JSON 412 默认冷却 **10 分钟**，429 默认冷却 **2 分钟**；合法
  `Retry-After` 优先，重复事件只延长、不缩短账号冷却；
- 冷却期内快速失败并向本地前端返回 HTTP 429 + `Retry-After`，不让请求线程
  睡几分钟，也不把限流伪装成“没有内容”；
- 登录态切换只清分类间隔和身份缓存，刻意不清账号冷却，避免通过切换身份模式绕过风控。

## 我们做的合规护栏（代码层）

1. 只登录用户自己的账号，不提供账号池/代挂；
2. 不内置任何破解付费墙、DRM 或课程保护的逻辑；
3. 下载物仅写入本地目录，不提供分享、上传或二次分发入口；
4. 所有 B 站链路共享统一并发、分类间隔和 412/429 账号级冷却；自动追更另有
   5 秒/UP 与 10 分钟轮询下限；
5. Web 服务只接受 loopback Host，浏览器来源头存在时必须严格同源，阻断 DNS
   rebinding 和跨站页面调用本地接口；
6. 弹幕、字幕、封面仅作本地存档，不采集他人隐私、不留存共享；
7. 页面动态文本统一转义，外部 URL 只允许 HTTP(S)，避免本地页面成为内容注入载体。

免责声明**没有法律豁免效力**，但能表明意图、降低被主张的主观恶意。建议包含：

- 仅供个人学习、研究、欣赏使用，用户自担责任；
- 禁止用于任何侵权、商业用途；
- 不保证工具持续可用，不对因使用导致的账号风险负责；
- 收到官方(律师函/DMCA)通知即配合下架。

其他建议：**匿名发布、不牟利、不接广告、不引流**；收到投诉立即响应。
